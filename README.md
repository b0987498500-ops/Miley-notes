# 麥麥筆記 (Miley's Study Notes)

歡迎使用 **麥麥筆記**！本專案是專為 Miley 量身打造的「學科觀念智慧手帳系統」。
無論是在看書、讀講義、自修複習或觀看解題時，只要將重點截圖或文字上傳，AI 助理便會自動提煉觀念、圖表、口訣與題型，並依照學科自動收錄至對應的筆記本中，免手動抄寫無負擔！

---

## 🎯 專案核心特色

1. **兩本手帳架構（複習 vs. 進度）**：
   - 📘 **【複習手帳】（第 1～4 冊）**：全面收錄國中七、八年級會考觀念總複習重點。
   - 📙 **【進度手帳】（第 5～6 冊）**：收錄九年級上、下學期最新課堂進度重點。
   - 🚀 **雙階層動線**：首頁第一步先點選想翻閱的筆記本，第二步挑選學科木牌，學科篇數徽章依手帳精準即時統計。
2. **自動分類提煉**：依據書本、講義或解題截圖內容，自動識別冊數並歸類至複習/進度手帳及「數學、自然、國文、社會、英文」五大學科。
3. **無需記錄日期**：不同於錯題本，本筆記專注於「學科架構」與「觀念邏輯」，以單元章節與主題式編排，**不記錄日期**，讓複習更聚焦於知識體系本身。
4. **兩側整齊有序伴讀插圖與長青藤蔓**：
   - 兩側空白處由卡通綠葉/春櫻藤蔓向下流暢延伸，沿途整齊穿插書堆、智慧貓頭鷹、古典地球儀、實驗燒瓶與滿分星星等手帳貼紙，秩序井然伴讀長篇筆記。
5. **精裝立體翻書體驗（Open Book）**：
   - 📖 **一重點即一頁**：以擬真展開精裝書造型呈現，具備中央書脊微凹陰影、絲質書籤帶、復古金屬護角與精美插圖。
   - 📄 **單元頁碼與直覺翻頁**：顯示「第 X 頁 / 共 Y 頁」，提供「上一頁 / 下一頁」大尺寸卡通木牌按鈕、左右懸浮箭頭、鍵盤方向鍵（← / →）與手機左右滑動翻頁。
   - 🔖 **章節快捷頁籤**：書頂陳列各重點書籤頁籤，一鍵直達特定頁數。
   - 🔍 **高清插圖與燈箱**：核心觀念插圖專屬展示框，點擊立即展開高清全螢幕對照（100% 純淨繁體中文資訊圖表）。
6. **大字護眼尊榮版**：基礎字體大器寬敞，支援 A- / A+ 無段無損縮放（最高可達 200%+），閱讀不費力。
7. **翻牌背誦模式**：速查大表單鍵進入遮蔽背誦，點擊卡片逐格揭曉，複習效率倍增。
8. **每頁刪除與回收桶一鍵復原**：若某頁已記熟或不需要，每頁最下方皆有一鍵刪除功能，並支援即時 Undo 與頂部回收桶管理。

## 💡 使用方式

1. **截圖或上傳文字**：在對話中上傳課本、講義、筆記或學習畫面的重點。
2. **AI 自動為您記筆記**：AI 助理會自動進行：
   - 辨識科目與所屬單元概念。
   - 提煉核心精華、口訣、公式與易混淆點（**不記錄日期**）。
   - 存儲圖片至 `images/{學科}/`。
   - 自動追加至對應學科的 `.md` 與 `notes_data.js` 中。
3. **隨時查閱**：
   - 在 VS Code 側邊或預覽窗檢視 Markdown。
   - 點擊開啟 [`index.html`](index.html) 享受極致舒適的護眼大字複習體驗！
