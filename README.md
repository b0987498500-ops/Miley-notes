# 麥麥筆記 (Miley's Study Notes)

歡迎使用 **麥麥筆記**！本專案是專為 Miley 量身打造的「教學影片重點筆記系統」。
在觀看教學影片、線上課程或課堂複習時，只要將重點截圖或文字上傳，AI 助理便會自動提煉觀念、圖表、口訣與題型，並依照學科自動收錄至對應的筆記本中。

---

## 🎯 專案核心特色

1. **自動分類提煉**：依據影片截圖內容，自動識別並歸類至「數學、自然、國文、社會、英文」五大學科。
2. **無需記錄日期**：不同於錯題本，本筆記專注於「學科架構」與「觀念邏輯」，以單元章節與主題式編排，**不記錄日期**，讓複習更聚焦於知識體系本身。
3. **雙重檢視管道**：
   - 📂 **Markdown 專科筆記**：各學科獨立 `.md` 檔案，支援 VS Code 原地大圖放大對照與側邊雙視窗對照。
   - 🌐 **互動式大字護眼網頁**（`index.html`）：支援多科切換、關鍵字即時搜尋、公式渲染（KaTeX）、字體無段縮放與高解析燈箱放大鏡。
4. **精美純淨排版**：全面杜絕未渲染代碼與亂碼，核心口訣、公式、比較表格一目了然。

## 💡 使用方式

1. **截圖或上傳文字**：在對話中上傳教學影片、解題影片或講義的重點畫面。
2. **AI 自動為您記筆記**：AI 助理會自動進行：
   - 辨識科目與所屬單元概念。
   - 提煉核心精華、口訣、公式與易混淆點（**不記錄日期**）。
   - 存儲圖片至 `images/{學科}/`。
   - 自動追加至對應學科的 `.md` 與 `notes_data.js` 中。
3. **隨時查閱**：
   - 在 VS Code 側邊或預覽窗檢視 Markdown。
   - 點擊開啟 [`index.html`](index.html) 享受極致舒適的護眼大字複習體驗！
